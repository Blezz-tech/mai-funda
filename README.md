# Отчёты в Typst — МАИ, каф. 806, «Фундаментальная информатика»

Два отчёта по лабораторным работам, перенесённые из ODT-файлов в Typst:

| Папка | Что это | Исходник |
|---|---|---|
| `lr/1/` | Лабораторная работа № 1 (ОС UNIX) | `Маркусь Евгений ЛР 1 Версия 4.odt` |
| `lr/2/` | Лабораторная работа № 2 (системы программирования на Си) | `Маркусь Евгений ЛР 2 (8) Версия 2.odt` |

## Сборка

```bash
./build.sh                  # собрать обе -> dist/lr_1.pdf, dist/lr_2.pdf
( cd lr/1 && typst compile --root .. main.typ out.pdf )   # по одной работе
```

Нужен только `typst` (0.13+; проверено на 0.15.x). Если CLI нет в PATH,
установите его (`cargo install typst-cli`) или используйте Python-пакет
`typst` (`pip install --user typst`, `typst.compile(...)`).
`--root ..` обязателен, потому что шаблон лежит на уровень выше.

## Структура

```
lib/lab.typ     шаблон только для лабораторных работ:
                страница, шрифты, шапка ЛР, report() — весь каркас пунктов 1–11,
                console() — текст из .txt (консоль, листинг, тесты),
                общие списки оборудования и ПО (default-equipment / default-software)
lr/1/ lr/2/     main.typ (только содержимое отчёта) + src/ (.txt) + img/ (рисунки)
```

`main.typ` каждой работы — это один вызов `report(...)`: в файле работы
лежат только отличия — номер, тема, цель, задание, содержимое пунктов 6–8 и
строки дневника отладки. Номера пунктов, их названия, пояснения в
скобках, оборудование, ПО, списки «Допущен к выполнению работы»,
«Пункты 1–7 отчета составляются строго до начала лабораторной работы.»
и подпись живут в шаблоне.

## Как написать новую работу

```typst
#import "/lib/lab.typ": setup, report, console

#show: setup.with()

#report(
  number: "3",
  topic: [Тема работы.],
  goal: [изучение и освоение …],
  task: [(вариант № 1) …],
  // необщие строки ПО — к общему списку (по желанию):
  software-extra: (
    "Утилиты операционной системы: nam",
  ),
  idea: [
    #console("/lr/3/src/commands.txt")
  ],               // содержимое пункта 6
  scenario: […],   // содержимое пункта 7
  protocol: [       // содержимое пункта 8
    *Сессия 1.*
    #console("/lr/3/src/session1.txt")
  ],
  diary-rows: (
    ("1", "дом.", "16.09.2025", "20:00", "Выполнение работы", "Нет", "Нет"),
  ),
  conclusion: […], // содержимое пункта 11
)
```

Общее ПО (`NixOS 26.11`, `zsh 5.9.2`, `gcc 16.2.0`, `vscode 1.144.0`) и
оборудование (`Процессор Intel® Core™ i5-12400F`, `ОП 32 ГБ`, `SSD 1 ТБ`,
`Монитор 23.8" AOC 24G2SAE/BK черный`) меняются в одном месте —
`lib/lab.typ` (`default-equipment` / `default-software`).

## Как что оформляется

| Элемент | В Typst |
|---|---|
| Поля 3 / 1.5 / 2 / 2 см, A4, 12 pt, нумерация | `setup(...)` из `lib/lab.typ` |
| Вся структура отчёта (пункты 1–11) | `#report(...)` в `main.typ` |
| Шапка лабораторной (заголовок + реквизиты) | внутри `report()` |
| Текст из `.txt` (консоль, листинг, тесты) | `#console("/lr/1/src/session1.txt")` |
| Картинка с подписью | `#figure(image("/lr/1/img/plot2d.png", width: 78%), caption: […])` |

Консоль, тесты и исходники — это просто `.txt`-файлы, скопированные из
терминала как есть. Никаких функций вида `test-case(...)` с массивами
строк и ручных отступов `#h(...)`: файл подключается одной строкой
`#console(...)` и печатается моноширинным шрифтом на светло-сером фоне —
как скопировано из консоли. Длинные строки переносятся по правому краю.

Текст отчётов лежит отдельно от оформления: чтобы поменять поля, кегль
или шрифт — правится один файл `lib/lab.typ`, тексты не трогаются.
То же самое работает и для общих блоков: название любого пункта,
оборудование и ПО меняются один раз в `lib/lab.typ`.

## Шрифты

В репозитории шрифтов больше нет — `typst` берёт их из системы.
Текст набирается **Times New Roman** (как в ODT-исходниках); в `setup()`
заданы цепочки с автоматической подстановкой — первая найденная гарнитура
используется, так что на машинах без MS-шрифтов подставится метрически
совместимый Liberation Serif (именно его LibreOffice сам подменяет вместо
Times New Roman в ODT):

* основной текст: `Times New Roman` → `Liberation Serif` → `Tinos` → `DejaVu Serif`;
* консоль: `Hack` → `Liberation Mono` → `Cousine` → `DejaVu Sans Mono`.

Цепочки лежат в `lib/lab.typ` (`default-body-font` / `default-mono-font`);
чтобы поменять гарнитуру или порядок — правятся они или параметры `setup()`
(`body-font:` / `mono-font:`). Если ни одно семейство из цепочки не найдено,
`typst` подставит свои встроенные шрифты (другой рисунок и толщина) —
в таком случае установите MS-corefonts (`ttf-ms-fonts` / `ttf-mscorefonts-installer`)
или croscore (`ttf-croscore`: Tinos/Cousine), либо `Hack`.

## Что поправлено по сравнению с ODT

* длинные строки протоколов больше не уезжают за поле (в ODT они
  переносились как попало);
* списки оборудования/ПО — настоящие списки, а не табы;
* в ЛР 1 управляющие последовательности терминала (`^[[?2027...`) в одной
  строке протокола вычищены — осталась нормальная команда `cat f2.txt`;
* исправлены опечатки: «Тюрингита» → «Тьюринга», «Не нормированные
  алгоритм» → «Ненормированный алгоритм», «полиндромию» → «палиндром»
  (в ЛР/курсовых, где встречалось), «в пунке» → «в пункте», «Hellow world»
  оставлено как в исходнике (это вывод программы);
* в дневнике отладки ЛР 1 поправлена противоречивая запись про номер
  группы (в ODT было «не 133, а 133»).
